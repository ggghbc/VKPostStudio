## Возможности VK Post Studio

- **Умное расписание по паттернам:** Задайте расписание публикаций один раз (например, 14:00, 18:00, 21:00 каждые 2 дня), и автоматический движок паттернов рассчитает все слоты без участия человека.
- **Генератор пакетной очереди:** Перетащите сотни изображений, выберите схему раскладки (по 1, 2 или 4 изображения на пост) и сформируйте структурированную очередь постов на недели вперёд за считанные секунды.
- **Аутентичный предпросмотр VK Smart Grid:** Просматривайте, как ваши изображения и текст будут выглядеть в ленте ВКонтакте перед публикацией.
- **Полноэкранный просмотрщик (Lightbox):** Мгновенно просматривайте оригиналы и миниатюры в высоком разрешении в один клик.
- **Безопасное и быстрое освобождение диска:** Освобождайте место на диске после отправки контента во ВКонтакте: приложение безопасно перемещает загруженные оригиналы файлов в корзину ОС или полностью удаляет их с диска, сохраняя локальные миниатюры и облачные ссылки.
- **Кастомизация интерфейса:** Несколько визуальных тем оформления и полная локализация на английский и русский языки.
- **На данный момент поддерживаются только текст и изображения.**

---

### 1. Движок паттернов (Smart Pattern Engine)

Автоматизируйте распределение слотов без лишних усилий. Укажите время публикации (например, `10:00, 15:00, 20:00`), выберите интервал в днях (`1` = ежедневно, `2` = через день, `N` = произвольный интервал), и движок сам распределит слоты без наложений.

### 2. Высокоскоростная пакетная генерация

Превращайте медиафайлы в запланированную очередь за секунды. Выберите десятки изображений на диске, настройте количество вложений в одном посте, прикрепите общий текст или набор хештегов и запустите процесс. Приложение само разделит файлы, выстроит порядок и распределит тайминги.

### 3. Просмотр стены сообщества

Изучайте стену целевого сообщества прямо внутри приложения. Загружайте опубликованные посты с пагинацией по 30 записей, просматривайте показатели вовлечённости и сохраняйте фотографии в исходном качестве обратно на компьютер.

### 4. Интеллектуальный фоновый воркер отправки

При нажатии на **«Отправить в ВК»** фоновый воркер выполняет полный цикл операций:

- На лету транскодирует изображения форматов BMP и TIFF в оптимизированный JPEG с помощью крейта `image`.
- Загружает изображения на серверы загрузки ВКонтакте (`photos.getWallUploadServer`).
- Формирует отложенные посты внутри отложки ВК с сохранением всех параметров (комментарии, режим карусели, подпись автора, рекламные метки).
- Автоматически сдвигает просроченные тайм-слоты (+2 минуты), предотвращая отклонение публикации со стороны VK.
- Добавляет рандомизированные паузы (2–4 секунды) между запросами для защиты процесса работы от спам-фильтров.

## Быстрый старт

### Скачать готовый релиз с GitHub

Просто скачайте портативный бинарный файл или пакет установки под вашу систему со страницы релизов и запустите приложение.

### Сборка из исходного кода

Убедитесь, что у вас установлены [Node.js 20+](https://nodejs.org/) и [Rust 1.77+](https://rustup.rs/) (а также C++ Build Tools на Windows).

```bash
# Клонирование репозитория
git clone https://github.com/ggghbc/VKPostingTool.git
cd VKPostingTool

# Установка зависимостей фронтенда
npm install

# Запуск приложения в режиме разработки
npm run tauri dev
```

### Сборка релизного бинарного файла

```bash
# Сборка оптимизированного исполняемого файла и инсталлятора
npm run tauri build
```

Исполняемые файлы и пакеты установщиков (`.exe`, `.msi`) будут сгенерированы в папке `src-tauri/target/release/bundle/`.

## Пошаговый рабочий процесс

1. **Добавление токена:**
    - Нажмите **+ Добавить токен** в шапке приложения.
    - Нажмите **Открыть окно входа в браузере** для прохождения авторизации ВКонтакте.
    - Предоставьте необходимые права и скопируйте полный URL из адресной строки браузера.
    - Нажмите **Вставить** и подтвердите ввод. Токен безопасно сохранится в системном диспетчере учётных данных ОС, а администрируемые сообщества загрузятся автоматически.
2. **Выбор цели:**
    - Выберите нужное сообщество или личный профиль из выпадающего списка в шапке.
3. **Настройка паттерна расписания:**
    - Откройте настройки паттернов (иконка часов) и создайте расписание (например, `3 поста ежедневно в 14:00, 18:00, 21:00`).
4. **Черновик поста или пакетная генерация:**
    - Введите текст, перетащите изображения в редактор или вставьте их из буфера обмена клавишами `Ctrl+V`.
    - Либо откройте **Пакетный режим**, чтобы запланировать десятки постов из папки с картинками.
5. **Проверка и предпросмотр:**
    - Нажмите иконку **Предпросмотр (глаз)**, чтобы оценить, как запись будет выглядеть в реальной новостной ленте ВКонтакте.
6. **Публикация во ВКонтакте:**
    - Нажмите **Отправить в ВК** на панели очереди. Фоновый воркер загрузит фотографии и перенесёт посты напрямую в очередь ВКонтакте.
    - Если несколько постов завершились с ошибкой, просто нажмите **Отправить в ВК** повторно.
7. **Очистка места на диске:**
    - Нажмите **Очистить локальные файлы**, чтобы безопасно отправить в корзину оригиналы файлов для уже отложенных постов, сохранив локальные миниатюры и ссылки на облако.

## Безопасность и приватность

- **Изоляция токенов (TokenVault):** Токены доступа и учётные данные никогда не хранятся в открытом виде в файлах баз данных или логах на диске. Они защищены на уровне подсистемы безопасности ОС (Windows Credential Manager).
- **Никакой сторонней телеметрии:** Приложение не выполняет запросов ни к каким серверам, кроме официальных эндпоинтов ВКонтакте (`api.vk.com`, `oauth.vk.com`).
- **Локальное хранилище SQLite:** Очереди, паттерны и пути к изображениям хранятся исключительно в вашей локальной директории пользователя (`%APPDATA%/com.vkpoststudio.app/`).
- **Изоляция разрешений:** Приложение настроено с соблюдением границ безопасности Tauri 2.0 (`capabilities/default.json`), доступ ограничен исключительно необходимыми диалоговыми окнами и областями файловой системы.
